# GlobeEditor

Re:ゼロから始めるGit生活

※このアプリケーションは、非公開リポジトリで開発していたものを、大学の講義の課題で利用するために一部修正し、公開リポジトリとして再構築したものです。

## 概要

GlobeEditorは、3D表示した地球儀の表面に直接描き込んで地図を編集する、Linux向けのデスクトップアプリケーションです。OpenGLとfreeglutで動作します。

地図は正距円筒図法の画像として扱います。平面の地図では形が歪む高緯度の地域も、球面上の見た目を確認しながら編集できます。

主な機能は次のとおりです。

- ブラシ、消しゴム、投げ縄、塗りつぶし、スポイトによる編集
- 編集の取り消しとやり直し
- 背景、中間レイヤー、編集レイヤーの3層による画像の合成
- 緯度による面積の違いを補正した、陸地と海洋の面積比の表示
- 編集レイヤーの保存と、合成結果のPNG画像への書き出し

## 同梱していない画像

中間レイヤー用の`map_middle.PNG`とインポート用の`insert.PNG`は同梱していません。使う場合は、実行するフォルダに各自で用意してください。
